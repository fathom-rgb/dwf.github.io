# 跃进 STRIDE

中文个人运动表现训练系统，静态页面，无后端与访问密钥。默认每周四练，心肺时间占主要比例，初始成绩保留约数与未知值。

## 使用

- 先在“档案与设置”补充开始日期、单次可用时间和确实可用的器械。
- 在“每周计划”学习动作，勾选完成项目，训练后提交实际时长、RPE、疲劳和疼痛。
- 点“下周调整”预览自动生成的计划，确认后启用；历史计划与日志保留。
- 每四周主动减量，分日复测替代原有训练模块。在“体测与趋势”录入真实成绩。
- 日志仅保存在当前浏览器 localStorage，不上传 GitHub，不跨设备自动同步。请定期导出 JSON 备份。

## 调整规则

1. 疼痛 >0，或任一次疲劳 ≥7 / RPE ≥9：有氧减量约25%，力量减组，暂停速度与跳跃。疼痛记录也暂停单杠；任何疼痛动作都先暂停。
2. 少于3次反馈：不加量。恢复模式需要新的良好恢复反馈才退出。
3. 完成率≥75%、已训练课次平均RPE≤6、所有记录平均疲劳≤4、无疼痛：轻松有氧增加约5%。速度与力量不同时加量，恢复后首次速度回归减量。
4. 每第4周额外主动减量约20%；至少两周适应且反馈良好后，才引入受控节奏间歇。

规则是透明的保守训练设计，不提供诊断，也不保证某个期限达到特定成绩。训练资料依据链接见网页设置页。

## 本地运行与验证

需要 Node.js 22 或更新版本，无需安装依赖。

```
npm run dev
npm test
```

打开 http://127.0.0.1:4178 。页面可直接部署到任何静态托管服务与子目录，资源使用相对路径。图解为内置 SVG 结构示意，字体加载失败时使用系统中文字体。

发布到 GitHub 时，只需将 dist 内文件放入网站的 stride 目录，并将该目录复制到 Pages 构建输出。日志与本地测试数据不进入发布文件。
