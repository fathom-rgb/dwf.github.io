## 二、技术要点

### 1. 结构与实现
- `index.html`：**单文件页面**（结构 + 内嵌样式表 + 内嵌交互脚本），照片和证书使用 `assets/` 中的本地图片
- `resume.html`：独立打印级 A4 简历页，与主站同一套设计语言，浏览器一键导出 PDF
- `assets/photo.jpg`：证件照（600×900 / 42KB，兼顾 Retina 与首屏速度）
- 全站中文注释，样式与脚本均按功能分区

### 2. 开源辅助工具
- **Font Awesome 6**（CDN）：全站图标
- **Google Fonts**：Noto Serif SC（标题）/ Noto Sans SC（正文）/ JetBrains Mono（编号与英文小字）
- 外部字体不可用时回退到系统字体；图标来自 CDN，离线时可能不显示，主要操作均提供可访问名称

### 3. 交互与动效
- Canvas 粒子背景、鼠标视差、滚动视差
- 打字机轮播文案、技能卡 3D 倾斜、按钮点击涟漪
- 滚动渐显（IntersectionObserver）、关于我 / 服务卡片交错入场
- **鼠标跟随光晕**（`data-spotlight`）：关于我卡片随指针位置渲染径向渐变高光
- 关于我数据 **数字滚动计数**、技能熟练度条滚动填充
- 导航滚动进度条、章节高亮（Scrollspy）、带环形进度的回到顶部按钮
- 亮 / 暗主题切换：首次绘制前读取有效偏好，未手动选择时实时跟随系统；存储不可用时仍可切换
- 修复打字机停在首句的问题；页面切到后台时暂停轮播，粒子在后台或离开首屏时停止绘制
- 所有动效均尊重 `prefers-reduced-motion`

### 4. 响应式
- 断点：1080px（导航压缩）/ 992px（双栏转单栏）/ 768px（汉堡抽屉菜单）/ 540px（移动端优化）
- `clamp()` 流式字号、`100dvh` 移动端视口、`scroll-padding-top` 锚点补偿
- 移动端抽屉菜单展开时锁定背景滚动；支持 Escape、键盘焦点循环和锚点焦点转移，切到桌面宽度时自动收起并恢复滚动
- 移动端 Hero 按钮全宽、关键触控按钮至少 44px、隐藏多余「联系我」与滚动提示
- 简历页针对手机优化为单栏阅读布局，长邮箱可换行，并提供返回主页与一键打印入口；屏幕字号与打印样式独立，打印时保留 A4 三栏技能布局
- `theme-color` 随亮/暗主题动态切换移动端浏览器地址栏颜色
- 禁用点击高亮与 300ms 点击延迟（`tap-highlight` / `touch-action`），防 iOS 字体自动放大（`text-size-adjust`）

### 5. 无障碍与健壮性
- **跳到主要内容** 跳转链（键盘用户可跳过导航）
- 复制条目支持键盘 Enter / Space 操作；剪贴板不可用或被拒绝时尝试兼容复制，并恢复原来的焦点与选择
- 项目筛选提供 `aria-pressed`、动态数量和读屏结果提示；证书使用原生 `dialog` 管理焦点，无脚本时仍可直接打开原图
- 无 JS 回退（`html.no-js`）、照片加载失败自动降级为印章占位图

### 6. SEO
- meta description / keywords、Open Graph 社交卡片
- Schema.org **Person + makesOffer** 结构化数据（三项服务已写入）

## 三、本地预览

直接双击 `index.html` 即可。如需更接近线上环境：

```bash
python -m http.server 8000    # 或 npx serve .
```

然后访问 `http://localhost:8000`。

## 四、部署

纯静态站点，可一键部署到任意静态托管平台：

- **GitHub Pages**：合并或推送到 `main` 后，仓库内的 Pages 工作流会自动发布根目录；首次使用时请在 Settings → Pages → Build and deployment 中选择 **GitHub Actions**
- **Vercel / Netlify**：导入仓库，框架选「Other」，构建命令留空，发布目录为根目录
- **Gitee Pages**：同 GitHub Pages 流程

> 注意：本地提交或只创建 PR 不会直接更新线上网站。需要把提交推送到 GitHub，并合并进 `main`；待仓库 Actions 页中的 `Deploy website to GitHub Pages` 任务完成后再刷新线上地址。

## 六、导出简历 PDF

1. 浏览器打开 `resume.html`（或点击主站导航「独立简历」）；
2. 点击右上角 **「打印 / 导出 PDF」**（或 `Ctrl / Cmd + P`）；
3. 选择「另存为 PDF」，即可得到与网页一致的 A4 简历。
