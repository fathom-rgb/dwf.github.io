# 戴文凡 · 文学 × AI 创作

从文字出发，把想法做出来。江南大学汉语言文学学生的个人主页与产品作品集，以真实项目连接文学背景与 AI 创作实践。

## 新增产品

作品统一维护在 `data/products.json`。新增一条产品数据即可自动进入完整目录，分类与数量自动更新。首屏展示前 4 件作品的快捷入口，超过 4 件时自动增加“查看全部”链接。首页已取消“正在重点做”精选区，完整目录默认不折叠。

编辑后运行 `npm run build`，提交数据、自动生成的 `index.html` 和新增图片。无需手工维护首页的重复内容。首页其余内容编辑 `templates/home.html`，不要直接修改生成的 `index.html`。

普通产品必需字段为 `id`、`name`、`description`、`category`、`status`、`href`、`action`；精选产品还需真实截图及 `imageAlt`、`imageWidth`、`imageHeight`。未公开发布的作品使用说明入口，并在状态中注明“作品展示”。详细例子与检查步骤见 [产品维护说明](docs/products.md)。

## 内容与设计

- **作品目录**：人物之间、大学文字模拟器、小账本、个人网站。全部作品提供名称、一句话价值、类型、状态与入口，并支持即时分类筛选。
- **创作方式**：梳理与表达、AI 辅助实现、体验与迭代。用具体实践代替技能百分比和未经核实的效率承诺。
- **关于我**：教育背景、已有证书、阅读写作与运动摄影等个人兴趣。
- **联系**：提供邮箱与复制邮箱；关于我中保留证书原图入口。
- **简历**：与首页一致的作品和定位，适合屏幕阅读及 A4 打印。

采用用户选定的“文学书页”方向：纸白、墨蓝、朱红，自托管中文宋体与水墨纸卷。首次访问默认浅色，已有主题偏好继续保留。纸卷为生成的独立艺术素材，桌面提供轻微 CSS 透视反馈；手机和减少动态效果时静止，不加载 WebGL。文字与入口均为真实 HTML。设计与素材记录见 [文学书页说明](docs/editorial.md)。

个人主标识采用深靛蓝与陶朱红的双鱼图案，用于页头与浏览器图标。06-A 抱书小法师保留在首屏作品索引下方，简历与分享预览使用双鱼标识。两款图案位于 `assets/identity/`。

## 文件与运行

生产页面使用原生 HTML、CSS、JavaScript，无生产依赖，也不依赖外部字体或图标 CDN。`npm run build` 先检查页面再生成 `dist/`，仅将公开资源发布到 GitHub Pages。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 自动生成的完整静态首页，断开脚本仍可浏览作品 |
| `templates/home.html`、`data/products.json` | 个人主页模板与统一作品数据 |
| `assets/home.css`、`assets/home-motion.js`、`assets/catalog.js` | 首页排版、一次性入场与目录筛选 |
| `assets/editorial.css`、`assets/editorial.js` | 文学书页布局、手机构图与桌面轻微透视反馈 |
| `assets/editorial/`、`assets/fonts/` | 纸卷 WebP 素材、自托管宋体子集与 OFL 授权 |
| `resume.html` | 简历；独立屏幕与打印样式 |
| `assets/certificate.jpg` | 关于我中可打开的证书原图 |
| `assets/unilifesim.jpg` | 真实游戏截图 |
| `assets/identity/`、`assets/identity.css` | 双鱼主标识、抱书小法师、浏览器图标与对应样式 |
| `scripts/serve.cjs` | 使用 Node 内置模块的开发服务器 |
| `sitemap.xml`、`robots.txt` | 索引说明 |
| `.github/workflows/pages.yml` | GitHub Pages 自动发布 |

直接打开 `index.html` 即可阅读。使用本地开发服务器时，无需安装依赖：

```bash
npm run dev
```

默认地址为 `http://127.0.0.1:4173/`。开发服务接受 `--host`、`--port` 和 `--strictPort` 参数，不参与生产运行。

## 交互与无障碍

- 首次绘制前恢复亮暗偏好；首页未手动选择时使用浅色主题。
- 桌面纸卷提供轻微指针透视反馈，没有持续动画循环；手机不拦截滚动，减少动态效果时静止。
- 手机导航使用原生 `dialog`，支持 Escape、焦点管理与背景滚动锁定。
- 导航链接关闭菜单后将焦点交给对应章节；切回桌面宽度时收起菜单。
- 全部作品直接展示；分类筛选作用于完整目录，作品笔记使用原生 `details`。
- 剪贴板权限被拒绝或接口不可用时尝试兼容复制，并保留手动复制说明。
- 提供跳过导航、可见键盘焦点、图片描述和减少动效偏好支持。
- 页面脚本不可用时，内容和作品链接仍可用，笔记可展开，不显示不可操作的筛选按钮。动效不使用持久隐藏样式；减少动态效果开启时取消动画。

## 改版验证

- HTML 标签、唯一 ID、页面与锚点引用、图片描述、结构化数据、站点地图和 JavaScript 语法检查通过。
- 浏览器检查桌面布局，以及 320、390、768 像素 iframe 视口中的响应式布局，未发现横向溢出；这属于布局验证，不等同于真机测试。
- 检查作品筛选、笔记展开、主题切换与刷新后保留、手机菜单关闭及焦点恢复、证书弹窗和复制反馈。
- 移除页面脚本的测试副本中，内容、原生笔记与证书链接仍可访问。
- 使用同一份打印 CSS 渲染 A4 尺寸测试页，核对单页内容高度；未依赖操作系统打印对话框验证。

## 发布与维护

合并到 `main` 后，现有 GitHub Pages 工作流发布仓库中的静态文件。确认 Actions 中的部署任务成功后，再检查线上版本。

本站是项目站点，地址为 `https://fathom-rgb.github.io/dwf.github.io/`。仓库名称不代表账户级域名；绑定自定义域名时需同步修改两页 canonical、Open Graph、结构化数据与站点地图。

`robots.txt` 位于项目子目录；搜索引擎通常读取域名根目录文件，项目站点地图也可通过站长工具提交。

更新内容时同步维护首页与简历中的教育背景、作品、证书和联系方式。新增能力陈述或结果数据前，先补充对应作品或可核实的记录。

打印简历时选择 A4、默认缩放，并关闭浏览器页眉和页脚。深色主题下会使用浅色打印样式。
